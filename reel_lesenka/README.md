# Как этим пользоваться

1. Положи скриншот вопроса подписчицы в `assets/images/subscriber_question.png`.
2. Открой эту папку в Claude Code и напиши:
   > Прочитай CLAUDE.md и сделай черновой рендер без голоса.
3. Посмотри черновик `out/draft_no_voice.mp4`. Правки пиши обычными словами («лесенка слишком мелкая», «цифры пусть считаются медленнее»).
4. Запиши голос по `script.md` и положи файл в `assets/audio/voiceover.m4a` (подойдёт и wav, и mp3).
5. Напиши в Claude Code:
   > Голос добавлен. Синхронизируй и сделай финальный рендер.
6. Готовое видео будет в `out/reel.mp4`, обложка в `out/cover.png`.

Перед публикацией проверь подписи-источники («Laufer & Goldstein, 2004» и «Nakata, 2013, 2017»). Если захочешь их поменять, скажи Claude Code, они вынесены в отдельные константы.
